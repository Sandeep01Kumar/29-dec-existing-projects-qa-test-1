## Hello World Node.js Server with Express.js

This project demonstrates a simple Node.js HTTP server using Express.js framework.

### Prerequisites

- Node.js v18+ (tested with v20.20.0)
- npm v7+ (tested with v11.1.0)

### Installation

```bash
npm install
```

### Running the Server

```bash
node server.js
```

The server will start at http://127.0.0.1:3000/

### Available Endpoints

| Method | Path | Response |
|--------|------|----------|
| GET | `/` | "Hello, World!" |
| GET | `/evening` | "Good evening" |

### Dependencies

- Express.js v5.2.1 - Web application framework for routing and HTTP handling
